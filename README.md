# alperen-selcuk/homebrew-tap

Homebrew tap for [Colima Desktop](https://github.com/alperen-selcuk/colima-desktop) — a desktop app for Colima on macOS & Linux.

```sh
brew tap alperen-selcuk/tap
brew install colima-desktop
```

or in one line: `brew install --cask alperen-selcuk/tap/colima-desktop`

`Casks/colima-desktop.rb` is updated automatically by the
[Homebrew workflow](https://github.com/alperen-selcuk/colima-desktop/blob/main/.github/workflows/homebrew.yml)
whenever a Colima Desktop release is published — do not edit it by hand.
